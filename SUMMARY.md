# Summary: Генератор отмазок

Одностраничный сервис на **vinext** (Next.js 16 + Vite). Пользователь выбирает ситуацию → получает отмазку с рейтингом правдоподобности → копирует текст. Всё на клиенте, без AI и бэкенда.

---

## Контент и логика генерации


| Было                    | Стало                           |
| ----------------------- | ------------------------------- |
| 3 ситуации, 18 шаблонов | **6 ситуаций**, **36 шаблонов** |


**Новые ситуации:**

- Не пришёл на встречу (`meeting`)
- Не ответил на сообщение (`no_reply`)
- Просрочил дедлайн (`deadline`)

**Антиповтор** — для каждой ситуации показываются все 6 шаблонов без повторов, затем пул сбрасывается.

**Род и грамматика:**

- Питомцы — готовые фразы (`pet_action_alarm`, `pet_action_homework`)
- Время — `{duration}` со склонением («5 часов», «сутки»)
- Имена — `PEOPLE` + синтаксис `{friend:просил|просила}`, `{colleague:затянул|затянула}`
- Проценты в deadline — отдельная переменная `{extra_percent}`

**Защита от сбоев** — fallback-шаблон, если для ситуации нет текстов.

## UI / UX

**Копирайт:**

- Бейдж: «Без нейросетей — чистая выдумка» (вместо «Работает на vinext»)
- Кнопка: «Скопировать и отправить» (без «боссу»)

**Мобилка:**

- Компактный выбор ситуаций — горизонтальный скролл чипов (emoji + заголовок), описания скрыты
- Скрытый скроллбар + `mask-image` для плавного затухания справа
- Отступы в скролле — hover не обрезается
- **Фиксированная панель внизу** — «Сгенерировать» / «Скопировать» + «Ещё одну»
- Ужаты шапка, отступы, кнопки

**Анимации** (`globals.css`):

- Плавающие blob'ы на фоне
- Fade-in-up, scale-in, shimmer при генерации
- Плавная полоска правдоподобности
- Feedback на копирование (зелёный / красный)
- `prefers-reduced-motion`

**Доступность:** `aria-pressed` на ситуациях, `aria-live` на блоке результата.

## Техника и edge cases


| Проблема                              | Решение                                               |
| ------------------------------------- | ----------------------------------------------------- |
| Гонка `setTimeout` при быстрых кликах | `useRef` + отмена таймера, фиксация `situationId`     |
| Смена ситуации во время генерации     | Отмена pending-генерации                              |
| Падение clipboard API                 | `try/catch` + fallback через `execCommand`            |
| Потеря отмазки при перезагрузке       | `localStorage` — последняя отмазка (`lib/storage.ts`) |
| OG без абсолютного URL                | `metadataBase` из `NEXT_PUBLIC_SITE_URL`              |
